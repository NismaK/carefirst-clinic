# CareFirst Clinic

CareFirst Clinic is an AI-assisted single-page healthcare website created for the AI Growth & Automation Associate assessment.

## Project category

Website Development

## Features

- Responsive clinic landing page
- Services section
- General health FAQ accordion
- Interactive care-pathway selector
- Appointment request form
- Client-side form validation
- Success confirmation state
- Keyboard-accessible interactions
- Mobile responsive layout

## Technologies

- HTML
- CSS
- JavaScript
- Claude for AI-assisted development

## Important limitation

This is a front-end demonstration. The form does not submit or store real patient information. The health information is general education only and is not medical advice.
